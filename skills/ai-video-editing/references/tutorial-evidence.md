# 操作镜头的制作与核验

拿到成音、录屏或已有导出时，直接处理本次交付涉及的镜头。每句先问一个具体问题：观众听完该能指到哪个对象，或者看出什么变化？答案写进现有分镜的“观众要看什么”栏。接着按这句话的用途选下面一行。几句话连续讲同一个操作，可以一直用同一段原录屏。

| 这句话在做什么 | 我选的素材和动作 | 什么时候切走 |
| --- | --- | --- |
| 指路，例如“在作者说明里找到安装方式” | 用当期真实项目页。先让人认出仓库，再沿同一页滚到目标小标题；接近时减速。裁到正文和必要导航，同屏只留一个阅读焦点。 | 停在那一行，按手机显示大小读完关键词，再让下一段接走。 |
| 让观众点、选、发或合并 | 优先截同一段实录里的旧状态、手势和新状态。光标到按钮时才强调它；按下和成功反馈是两个事件，中间等待可压缩。屏幕变化很小时，只推近变化处。 | 观众能从新增行、更新的标题或发出的消息确认结果。若只是让 Agent 去做，把镜头停在请求已发出；实际成功要另有证据。 |
| 解释前后区别 | 同一对象、同一尺度，先给旧版，再沿变化方向揭开新版；让观众说得出哪一项变了。两个版本必须来自能核验的各自状态。 | 新状态能独立读懂。两张图本来一样时，回找有差异的素材或收短这段。 |
| 描述处境、列举工具或转入下一节 | 处境找能看见相应行为的真实动态素材；工具按提及顺序依次入画。观点转折可回真人。先检查前后镜用过的主体、运动方向和声音，再决定接动作、接声音或直接切。 | 观众已认出工具或听懂转折。重复使用同一画面，要能指出本次新增的信息。 |

**备料。** 搜索用“主体＋动作＋可见结果”，如“浏览器 搜索项目 进入作者仓库”。筛选的是具体可用秒段。确认画面回答了这句话，再登记来源、用途、许可及剪入剪出位置。真实按钮、真实项目输出以同版本界面为准；情境补镜、模拟终端或原创网站可以用于说明概念，分镜注明示意范围。素材不齐可剪到已证实的那一步。缺点击前状态时，优先回到原录屏或安全演示环境补录。本期下载、付费和上传范围沿用主流程已有授权。

## 把动作放到那句话上

1. 选定已锁定的声音版本。先用配音工具已交付的词时码，或同一条人声已有的本地转录。找出真正改变画面的短语，如“合进主分支”。重复词结合该句上下文选中一次；识别不清的英文、专名、否定词和数字，在这小段回听。只有整句字幕时，听到关键发音再在时间线上落标记。估时用于分镜讨论。
2. 分开记“提到按钮”“实际按下”“结果可见”。字幕可跟发音，点击声跟按下，成功音跟结果出现。口播只是预告动作时，保持旧状态给观众找位置。速度改变、换声或删去等待后，取新时间线的标记复核受影响的镜头。
3. 用同一成片时钟驱动高亮、画面和声音。单段词表从该段音频开头计时；节选从工程记录的**音轨截取点**换算。逐句变速、重排或拼多段时，用各自片段的映射或在最终音轨重新定位。把时码依据写在本镜已有的备注里即可。

下面命令从技能目录执行，文件名、坐标和时间换成本期数据。查已有词表只用 Python；滚动长截图需要 Pillow 和 FFmpeg，查声音需要 FFmpeg 与 ffprobe，查固定画面区域另需 Node.js 和[随包的图像比较依赖](workbench-video-tools.md#局部画面复查)。工程已有同等功能时直接用原工具。以下两个词表格式都可读取：

```text
python -X utf8 -B scripts/find_spoken_anchor.py paragraph.wav.timestamps.json "合进主分支"
python -X utf8 -B scripts/find_spoken_anchor.py timings.json "合进主分支" --line L33 --line-words-local --origin 174.5655
```

第二行只用实际知道音轨从 174.5655 秒截取的这份节选演示；换片时从新工程取数，整片查询省略 `--origin`。工具列出匹配上下文和原时间，重复命中全部返回。命中半个词只给覆盖它的整词区间。零匹配时回听或查另一种写法。画面首变帧仍从编码后的片子看。需要核图时，[区间审片](../scripts/review_window.py)可以把同一时钟的词表、波形和这一小段的画面放在一起。[词时码定位工具](../scripts/find_spoken_anchor.py)

## 做出能读清的镜头

长网页能从原图清楚辨认正文时，可直接用[长页滚动工具](../scripts/render_evidence_scroll.py)生成静音镜头。取原图中目标行的纵坐标，按话语设置到达时间，按阅读量设置停留。横屏读小字时先裁掉无关侧栏，保持标题、目标行和必要上下文在同一窗口。只有一屏内容时可以直接用原图定镜。滚动中保持视线稳定；若需要描圈，待页面停稳再开始，随后围绕同一位置放大。

```text
python -X utf8 -B scripts/render_evidence_scroll.py --image readme.png --output readme-usage.mp4 --start-y 1040 --target-y 1378 --crop-width 480 --target-screen-y 0.5 --scroll-start 0.4 --arrive-at 2.8 --read-until 4.8 --duration 6 --size 1280x720
```

示例保留 480 原图像素宽，目标行停在画面中线。若观众需要读完整段正文，取足原文宽度；若只读某条命令，确保整条命令入画。给 `--end-y` 可在读完后滚向下一段，省略时就停到切镜。成品素材的时码从零算，放回主时间线要加该镜入点。

用真实录屏时保留鼠标与界面的空间关系。下一个动作仍在该页，就从刚停住的位置继续；换到 Agent 聊天时，可用同一段已选中的项目名或链接把视线接过去。演示输入时保留输入框、输入过程和发送后消息所在的位置。静音镜头导入主时间线后，保留本期原人声并按可见动作配置声音。

## 从导出找出错点

**画面。** 从最终导出取变化前、动作中、结果后三个时刻。确认对象始终可辨，再连看中间动作。固定位置的文字/图标有独立核过的前后状态参考时，用[画面状态检查](../scripts/check_scene_evidence.py)比对那一小块，能筛出提前出现结果或前后相同。选能区分状态的区域，避开正在闪的光标、播放器和字幕。已经推拉、切窗或重新排版时，直接看关键帧和连续回放，或在对齐的同一构图中核。像素变化的含义靠实际内容判断。

```text
python -X utf8 -B scripts/check_scene_evidence.py sample.mp4 --times 11.44,13.76,14.54 --roi 1190,520,340,60 --reference-before reviewed-before.png --reference-after reviewed-after.png --max-diff-ratio 0.005 --output new-review
```

示例坐标和编码容差来自一条 1920×1080 短片。裁切、分辨率或编码有变化时，用本镜两份已读过的参考帧确定可接受差异。[本地画面对比依赖与入口](workbench-video-tools.md#局部画面复查)

**结果能停多久。** 在导出中找第一帧可读的结果和切走的时刻，按拟发布速度缩到手机观看宽度，试着认出“哪个对象、哪儿变了”。若只能在暂停时看明白，优先延长结果、让焦点占更多画面，或让下一句旁白提前进入而画面继续停留。排一下相邻镜头，避免自己先看到结果才猜出应该看哪。不设全片通用的最低秒数。

**声音。** 从原工程导出带前导静音、与成片同长同起点的新增音效分轨，再取最终混音。用[动作音效检查](../scripts/check_action_audio.py)筛出约定窗口内缺声、起声偏移和疑似重复的位置。在带声成片回听这些点，判断响的是什么、是否被盖住、是否与画面相配。单个音效素材从零开始，不能直接当作已混到整条片里的分轨。

```json
{"timebase":"program","cues":[{"id":"send","seconds":3.44,"origin":"added"},{"id":"open","seconds":5.12,"origin":"existing"}]}
```

```text
python -X utf8 -B scripts/check_action_audio.py --cues action-cues.json --sfx added-sfx.wav --original screen-audio.wav --mix export.mp4
```

已有工程的 `events[].time` 若是成片秒数可直接使用。原录屏含点击用 `existing`，刻意让新增音效静默用 `silent`。只有混音时，可以先逐点试听；工具只能标出待辨别的时窗。如同版工程能在相同增益和起点单独关闭某轨，可对照该轨有／无时同一小段的导出。审片备注区分“该轨有起声”“已经写入最终混音”“实际回听能辨认”。有源数据才填写对应结论。

## 返修和外部工具的选择

在已有审片单上记一行：镜号和导出版本、哪句哪一秒、应该看到／听到什么、实际结果、重验位置。只读审查时直接在回复中给这条记录。只改动作时复用原人声和已确认镜头，重剪这一镜及接缝。同类问题先查相邻操作链与共用组件，发现同源缺陷再扩大范围。检查一张参考图或一个时窗，就标这次实际确认的范围。

本页的取材、定时、滚动、声音和检查可在自有入口运行。外部执行器只有在需要某个具体产物时才替换这一步，例如“输入一条人声与稿，返回同版逐词时码”。先看已有条件、许可证和外传范围，再用同一段成音、同样输出规格比较可读性、声画对应、从开始到交片的耗时和费用。已验证有收益的版本及输入输出约定记入既有工作台清单。外部工具不可用时，回到原工程的标记、关键帧、分轨和局部回放继续剪。[方法来源和许可](../upstream/sources.md#录屏教程与口播动效)
