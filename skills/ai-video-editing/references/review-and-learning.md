# 审片、经验积累与垂直领域派生

## 每期留下下一次能用的东西

若本期目标是主动咨询或帮助观众作选择，回填[决策型视频复盘](decision-led-video.md#发布后看哪些问题还没答到)。记清实际追问、对应镜头和咨询来源；没有可归因数据就保留空缺，供下一期验证。

开工前从所属项目的近期复盘找同类镜头，先看用户亲自保留、替换或否决过什么。每次审片轮次在项目已有审片单追加一行；没有旧单时在项目内存一份可持续更新的剪辑复盘。可只发方案时记录“预估／待验证”。已完成的片不凭印象补写用户认可、播放数据或真机观感。

| 项目／版本／时码 | 原来怎么剪／用户原话 | 修订及结果／证据 | 下一次如何调用／范围 |
| --- | --- | --- | --- |
| 例：桂工转专业 v01→v02，0:30–0:41 | 用两张定格代替拨动；用户指出两年都要播 | 找回对应两份 XLS，按原行连续滚动，2025 重点条件减速停留。核验成片首、中、末行及帧间运动 | “连续浏览表格”镜头先找原表或足够长的录屏，关键行按台词停留。此项未包含发布后数据 |

每期判断一件最应沿用的事、一件待改的事及下轮如何验证。用户明确的偏好立即写入该项目约定；有实际片段和验证的通用做法进入动效库或共享工作手册。单个学生账号的审美保留在校园配置，需要跨题材验证再推广。素材条目记录动作、镜别、用途、来源、许可与代表秒段，检索已有同类条目后补充。别把身份信息、密钥、原始学生资料或未授权录音写进共享技能。这个工作区的稳定跨项目经验按已有项目自己的工作手册归并；项目复盘与用户个人记忆分开。

**审片证据**可包括最终文件的解码与声画时长、带声回放、关键帧及播放速度、字幕首尾和重点词、隐私遮挡过渡帧、音乐让位与音效落点，以及用户指出要返工的时码。大画面运动必须回放，静态联系表只能说明取样帧。依据当期内容挑有意义的项，不把可试听写成听过。

剪点密集或合成复杂时先本地出低清带声审片；在关键切换前、切换点和切换后抽连续短条带，找闪帧、字幕越界、圆框突然换角与隐私露帧，再正常速度回放。有问题按镜号修那一段，复用原主音轨。最终导出独立解码，比较音轨与片尾时间；要求完全保留原混音且编码可直通时，可校验音频数据哈希。[上游剪辑审片与导出方法](../upstream/gitethanwoo-video-editing/SKILL.upstream.md)

## 改风格先看连续样片

要调整整片的节奏、转场、功能动效或字幕强调时，先挑能代表改法的一段带声样片，包含前一镜切入、目标镜头和切出后的下一镜。把点击前状态、触发、变化与结果停留放在同一段里，按拟发布速度回放并检查手机阅读效果；孤立的动效循环或几张静帧不足以判断连续观看。说明这次改了什么、还未验证什么，获得用户对该样片的明确确认后再扩展到全片；已有同范围的确认可沿用。样片路径和待确认状态记在项目审片单，不把“已生成”写成“已认可”。

发布复盘把三件事分开记：用户实际发布时动了哪里、用户明确认可的剪法、下一期还要由剪辑师判断的参数。本期发布倍率记在本期复盘，不自动沿用到下一期；下一期按[当期原声与画面定速](motion-and-sound.md#按本段的听觉与阅读负担定速)。留存、完播等效果需要对应发布数据才能判断。

样片含教程圈注时，核对干净原页面、起笔、半圈、成圈、推近结束及停读这些状态，并按拟发布速度带声连看：起笔是否跟词或操作，观众是否能看出圈正在画，圈和推近是否始终指向同一目标，停下来后能否读清。素材原有的圈、整圈闪现、坐标漂移或一成圈就切走，按具体时码退回；关键帧能定位问题，不能替代运动回放。

转场既看这一对镜头是否好看且贴合语义、共同元素是否连续、方向与新焦点是否清楚，也看整片是否机械重复。样片通过只覆盖这段已确认的改法；铺开后仍要带声通看全片，并在项目审片单记录保留、替换或有意重复的边界和理由。不要以种数、每镜都加效果或抽查几个切点代替整片判断。

## 成片文件怎么验

反馈只点某一句时，从导出的审片文件取这句话及前后的画面与声音。以通用技能目录为起点，运行 `python -X utf8 -B scripts/review_window.py 审片.mp4 7.4 11.2 --words 逐词时码.json --frames 6 --output 新的检查图.png`，输出路径指向项目临时目录。需要 FFmpeg、FFprobe、Pillow、NumPy。可省略 `--words`；提供时，逐词 JSON 用数组或含 `words` 的对象，词有 `start/end` 秒和 `text` 或 `w`。剪后画面配剪后时码。图上部等间隔取样，首末图分别对应范围两端；下部波形和标签帮助定位，个别字会因版面省略。临界剪点可缩到前后数帧，连续操作回放完整过程。检查图里的机转文字只作定位。若要判断音效听感或配乐是否压字，用实际导出在同音量下带声回放。

改过口播或剪点，就从变更句开始按新时码核对 B-roll、字幕、圈选和音效；被剪掉的句子所绑定的图层逐一复核。只换配乐时复用锁画底版。有版本管理的工程给当次定稿标记，项目用文件管理时记下底版和修订时码。沿用已批准且范围相同的素材；换了作品、版本、费用或用途时只提变化项。

在通用技能目录运行，可以直接用绝对路径代入下面的文件名。脚本调用本机 `ffmpeg` 和 `ffprobe`，只读取本地文件，输出 JSON。发现结构错误会返回非零退出码。

```powershell
python -X utf8 -B scripts/check_export.py "审片.mp4" --srt "成片.srt" --require-audio
python -X utf8 -B scripts/check_export.py "配乐版.mp4" --same-picture-as "带音效的无配乐底版.mp4" --loudness
```

- 交完整版时，回读导出的主视频和音轨直至片尾。记录解码帧数、尺寸、帧率、声道；已知交付时长可加 `--expect-duration 秒数`。静音作品省略 `--require-audio`。成片有字幕时传入对应的 UTF-8 SRT，检查起止和越界。重叠条数作为复看提示，有意重叠的双人对话可以成立。
- 单独改音且视频流直通时，用 `--same-picture-as` 比压缩画面、编解码参数、包时间戳和持续时间。若流程明确需要重编码，这项不适用；另将对应帧对齐审看。需要改声画节奏时重新按真实语音检查剪点。
- “有音轨”只能说明轨道存在。用 `--loudness` 在最终文件的默认音轨测综合响度（LUFS）和真峰值（dBTP），全静音或短到无法测量的读数可为 `-inf`。实际听开头、最密台词、音效动作及片尾，标出被盖住的字或错位动作。需交两种混音时，按同一播放音量切换两版。只有本机信号检测时照实写明。烧录字幕的错字、作品授权或某一帧是否露出个人信息，在对应镜头另验。

审片反馈尽量写成“时码＋观众看到或听到了什么＋改成什么＋怎么判断已经改好”。例如“01:29 口播说我开发了小程序；主画面换作者确认的当期首页，让角色退场；缩到手机观看大小还能认出所指入口”。下轮复审先回这个时码，再查同类镜头。这样每条退回意见都有去处。

## 整片定稿后归档与清理

交付整片候选时给出可播放的文件和明确版本。还没定稿就问一句：“这支《片名》是整片终稿，还是还要改？”有多版时列出具体文件让用户指认；用户已点名终稿或交回实际发布文件，就按该文件收尾。样片获准只代表可以沿用这段剪法。

1. **归档用户选中的文件。** 放进项目约定的 `exports`、`published` 或指定正式目录。在项目现有审片记录里记下版本、路径和对应工程。回读成片到片尾；若从审片目录复制，核对两份文件的哈希。若用户在别处又配乐、调速，以用户交回的文件归档，已知的外部修改记在旁边。
2. **从终稿工程倒查依赖。** 查时间轴、素材表和渲染／混音脚本实际读取的文件，包括嵌套工程、旧版底片、独立音轨与字幕。保留原始口播和录屏、可复剪工程、使用的生成或下载资产、许可记录、指定保留的版本，以及另有用途的素材。若唯一输入还在临时目录，先复制到稳定目录、比对内容、更新引用并验证可读；引用不清的单项先保留。
3. **清掉确定无用的工作副本。** 仅在当前使用者已授权清理且整片终稿已明确时，按授权范围清理本片已淘汰且无引用的审片导出、重复试转码、可重建的代理、渲染缓存和检查帧。终稿确认本身不等于清理授权，不能继承作者或其他使用者的个人授权；已有明确的同范围清理授权可沿用，缺少时先列候选供当前使用者决定。用程序列候选的绝对路径和大小；同名、疑似重复时核对修改时间及内容或哈希。只处理本项目和能够核实属于本片的临时目录内的具体文件，解析路径并避开链接跳转；目录名叫“旧版”或位于临时区都不足以判定可删。用户指定保留的项和其他项目的文件保持原位。
4. **复查与回报。** 核对终稿能打开、保留的工程和素材链接仍可读，更新索引。报告终稿与素材索引位置、实际移除的文件数、按文件大小合计的容量、因依赖或待辨认而留下的项目。进入回收站的容量另列，不能算作已经释放的磁盘空间。

## 派生一个新领域

用户说“再做一个产品／旅游／访谈剪辑 skill”时，写一个领域子技能，让它调用通用的逐句包装、下载确认、时间轴、验收和复盘流程。子技能只维护领域差异，用下面五项即可启用。独立迁到其他宿主时把通用技能同时安装或把引用按目标位置解析。

| 配置 | 要明确的内容 |
| --- | --- |
| 触发与交付 | 面向谁、怎样点名、横竖屏、单期用途、正常交付件 |
| 画面语法 | 代表性参考片、字体和安全区、人物与主体站位、哪些动效有用 |
| 证据与补料 | 领域事实来源、只能由用户提供的原件、敏感字段如何在源头裁掉、如何标明示意 |
| 声音与素材 | 栏目音色、音乐风格、动作音效密度；本地库地址、站点和授权约束 |
| 经验归属 | 项目复盘文件、典型时码、用户保留或退回的版本；只把跨领域方法回流通用层 |

**派生实例如软件教程。** 入口识别“讲一次导出操作”；本期要求真实录屏中看清点击前和导出结果。光标旁的菜单始终占主画面，真人圆框让开菜单。可复用通常版的“按钮推近”“动作落点音”，人物采访或校园吉祥物不带进来。共享流程升级时子技能仍沿用同一份来源。
