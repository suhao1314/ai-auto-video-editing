# 动效、字幕和声音

## 可以按触发动作复用的镜头

以下参数是试剪起点。先看源画幅、平台控件、安全区、内容密度和说话速度，再决定动作的幅度与时长。每次写清触发的口播词、素材自身坐标、成片画布位置、动作结束状态。把实际采用并通过审片的变体登记到项目复盘。

设计可复剪的动效时，用同一个成片帧号推导位置、缩放、透明度与音效落点。镜头从入帧开始显示，在出帧前一帧抵达末态；需要观众读到的结果单留停留时间。图层分别保存，重渲相同时点应得到同一构图。若后端用浏览器渲染，避免用系统时钟或未固定的随机数驱动关键运动。[HyperFrames 时间轴做法](../upstream/heygen-hyperframes/SKILL.upstream.md)

| 触发点 | 怎么做 | 回放时看什么 |
| --- | --- | --- |
| 讲到某个按钮或输入框 | 先保持原界面方向。口播说到按钮名时，以按钮中心为锚点推近；需要时加环或光标。点击后留到界面反馈或结果出现，再退回全景 | 按钮文字是否看得清；推近有没有裁掉菜单、键盘或结果；录屏是否已带点击音 |
| 小图标、符号或短词首次出现 | 在需要辨认它的词上弹入。可从 88% 到 108% 再回到 100%，用缓出或轻弹簧，约 0.2–0.4 秒。保持锚点稳定、回落后留足识别时间 | 连看同段是否抖眼；小图标轮廓是否干净；一组图标按提及顺序进场 |
| 从口播切入操作或证据 | 真人讲话时保留表情。开始展示主体时，将已有真人画面用圆形遮罩缩入空角，必要时柔和描边；保持同一镜讲话同步，主画面留给 B-roll。关键区域或字幕冲突时换角或暂时退场；阿桂栏目可按角色规则处理 | 人脸、画面主体、按钮、字幕互不遮挡，脸没有被错误裁切。只有声音时用全屏 B-roll 或授权角色 |
| 一张表格需要从上向下看 | 用原录屏或完整真实数据，保持表列关系，视窗连续向下浏览；念到关键条件时减速、圈出同一原行。涉及隐私的截图先裁到许可列再施加运动 | 抽查进入、中段、末段和逐帧运动；确认方向与原行顺序，正式输出不能闪过未遮挡的一帧 |
| 数据在增长或卡片需要比较 | 先核对数据、单位、时间和比例，再逐步揭示。3D 卡片的转面要带出比较项；旋转数据图以刻度与数值可读为准。静态图层可生成，数值、轴和中文用可编辑图层控制 | 末值和源表一致，中间动画不被误读为另一次观测；关掉效果仍能读出结论 |
| 人物身后出现大字 | 给人物主体建立遮罩，背景、大字、人物按这个顺序分层；出现时刻跟重音，避开脸和字幕。发丝遮罩不稳就改到侧面留白 | 检查动作最快的几帧和发丝边缘；大字与底部字幕分别承担不同信息 |
| 动作或话题发生变化 | 继续同一操作用匹配剪接；真实空间变化可用硬切；需要观众先听下一场或保留上一句尾音时用声音先入或后出。转场占用的帧与跨镜声音一起进时间轴 | 切后是否理解“在哪儿、发生了什么”，是否误删按下、载入、反馈这几个动作 |

## 字幕按声音校时

有原声时保留一条主音轨。用 ASR 获取字词时刻，再按实际听见的专名、数字、单位、断句人工校正。文稿与成音不同优先成音，政策条件或数字有实质冲突时在审稿处说明。长句按语义分屏；保持每次显示足够长，把句子定位和字幕分屏作为两级时码。多个片源、变速或剪除停顿后从同一时间映射导出字幕、动效和音效，避免重复累计四舍五入导致片尾漂移。

选一种能显示中文的字体与一个强调色，按发布画幅给底部和两侧留安全区。浅底和暗底各抽一帧检查对比；忙乱背景可加细描边或局部半透明底。关键词的放大、变色或下划线跟实际发声时间，通常一屏突出一个词，金额、百分比、专名和否定词保持完整。检查上限行长、换行后的数字单位、圆框遮挡和平台控件；看手机尺寸的静帧，再正常速度回放。保留可编辑 SRT；需要逐词效果时从同一数据派生 ASS 或渲染图层。

## 混音先听原片

1. **选 BGM。** 在包装表写这段需要的速度、乐器、情绪和进退点，例如“轻打击、无歌词，步骤演示时降低，最后一句收尾后淡出”。严肃证据、密集数字或原声情绪较强时，留白也可以。可用本地已获授权音乐、许可匹配的音乐库，或获准后用 Suno 等生成。确认生成时账户方案、该段成音的用途授权、成本；按当时有效条款留证。音乐网站试听和下载仍遵守逐项确认。[Suno 的生成时权利说明](https://help.suno.com/en/articles/2416769) · [订阅前生成曲目的说明](https://help.suno.com/en/articles/2425729)
2. **写 SFX 提示表。** 给每次需要听到的动作写“镜头、成片时码、事件、声音、时长、已有原声／需新增”。键入从第一组真实按键开始，停手即停；鼠标点击只对准按下或反馈的那一帧；图标弹入可配短而轻的落点音。连续文字排版不必每字一声。真实新闻、静态数据或情绪停顿没有合适的声音就留白。
3. **再混音。** 分清人声、已有混音、音乐、环境和短音效。用户给已混合的音轨时先识别原有音效与乐床，按要求保留原混音；整段无新增声音且需无损时优先原音轨直通。需要加声时使用独立轨道，在关键辅音、数字、姓名和动作原声前让位，音乐在人声进入时做平滑闪避；用短淡入淡出避免爆点。保持可追溯的原轨。
4. **实际验听。** 分别听口播单轨、合并音轨和最终导出，检查开头、最密集的打字段、章节交接与片尾。测响度、真峰值与声画同步，依据目标平台交付要求调整；记录实际听感或实测范围。无法通过扬声器、耳机或真机验证时注明边界。
