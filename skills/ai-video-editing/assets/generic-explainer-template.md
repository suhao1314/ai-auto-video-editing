# 通用横屏证据画面模板

模板适用于软件教程、服务说明、工具测评和口播中的单个重点。主画面始终是当期真实录屏、截图或实拍。深色外框、浅色标题区、步骤条和底部字幕只是让观众更快找到证据，不能把示意卡片当成真实产品。

## 使用

用已经安装的 FFmpeg 渲染。`--input` 可传入 PNG、JPG、MP4 或 MOV，模板会保留输入比例并把它放入主画面窗口。视频默认从 `--start-seconds` 播到源片末尾，绝不循环。截图默认 12 秒，可用 `--duration-seconds` 改短。

```powershell
python -X utf8 -B generic-explainer-template.py `
  --font "./font.ttf" `
  --input "./input.mp4" `
  --output "./exports/step-one.mp4" `
  --start-seconds 8.4 --duration-seconds 11 `
  --kicker "产品实操" --title "三步完成导出" `
  --step-one "第 1 步 · 确认文件" `
  --step-two "第 2 步 · 点击导出" `
  --step-three "第 3 步 · 看生成结果" `
  --focus "620,320,160,62" `
  --action-at-seconds 3.1 --result-at-seconds 8.0 `
  --caption-one "选中《项目进度表》，准备导出" `
  --caption-two "点“导出”，保存位置就在这里" `
  --caption-three "导出完成，文件已经出现在下载目录"
```

没有真实素材时，只有为了测试模板才可用 `--demo`。它生成中性示意界面，文件名和分镜必须标为“示意”，不能代替实际产品步骤、数据或新闻证据。

## 进时间线前检查

- 真实输入要有操作前、触发动作、结果稳定三个状态。讲按钮时停在按钮文字完整的帧，讲结果时停在结果可读的帧。
- `title` 讲观众得到什么，三段 `step` 和 `caption` 分别承接原状态、动作与结果。三者不重复堆同一句话。侧栏标题最多两行，步骤与底部字幕最多一行，过长文字会加省略号，完整句子留在当期字幕轨。视频的 `--action-at-seconds` 和 `--result-at-seconds` 从模板输出的 0 秒开始计，必须对应真实动作和结果。没有明确位置时不要传 `--focus`，模板不会凭空框一个区域。
- 若输入里已有可识别人物，检查整段运动中的隐私遮挡。模板不会自动识别人脸、账号或敏感信息。
- 需要配拟音时，声效跟真实点击、输入或结果出现的时刻对齐。该模板不自带音乐和音效。

模板输出是横屏 1280×720、30 fps、静音的 H.264 MP4。需要人声、字幕或音乐时，在项目时间线中与对应音轨混合，之后用通用技能的 `check_export.py` 复核导出。
