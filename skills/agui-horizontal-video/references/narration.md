# 原声、配音与音效

有用户提供且可使用的原声时，优先保留完整原声和已混入的合适音效，按实际语音排字幕。已定稿的来源声音和适合的内嵌音效要锁定；只补需要补的拟音，避免整段重新配声。不要把未获许可的第三方声音放进公开技能包。只有文稿时优先试听适合中文校园口播的 Breeze TTS 2 风格，再比较本地可用音色；这是试听偏好，不代表当前机器已接入。逐一核对生成音频、模型权重、具体音色及商业发布用途的许可，再按实际音频时长制作字幕与镜头。免费试听或应用源码许可不能替代具体音色的商用权利。

在当期私有工程记录：原声提供者或合成引擎、许可依据及核验日、音频哈希、时长、声道、音效来源、音乐作品与授权范围。用户提供播放器录屏不自动授予公开发布权。配乐记录入点、出点、淡出和人声让位；保留原调原速时写明。独立拟音要对准可见动作的起落，导出后从最终 MP4 试听，不能只依据时间轴或中间 WAV 判断。

涉及学校名称、楼号、字母和数字的口播，逐句试听读音，字幕按最终核定文稿排。未接入或未测试的 TTS 只可列候选，不写成当前工作流已支持。
